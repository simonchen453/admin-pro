# AdminPro 视觉方案 · 纯白 / 墨黑

静态设计稿，不依赖构建，双击 HTML 直接打开即可（联网时加载字体，离线自动回退到
PingFang SC / 微软雅黑）。

| 文件 | 说明 |
|---|---|
| `users.html` | 用户管理（**列表页范式**，全站 20 多个管理页共用这个骨架） |
| `permissions.html` | 权限矩阵 + 角色明细 |
| `theme.css` | **设计令牌，唯一真源** — 已搬进 `frontend/src/styles/`，两边保持逐字节一致 |
| `ui.css` | 组件层 — 已搬进 `frontend/src/styles/`，两边只差稿件导航条那 35 行 |
| `shell.js` | 仅设计稿用，注入侧栏/顶栏。**落地时不要搬**，由 React 组件替代 |

`dashboard.html`、`login.html`、`antd-theme.ts` 已删除 —— 它们分别落地成了
`Home.tsx`、`Login.tsx`、`src/config/theme.ts`，真实代码就是它们唯一的版本，
留一份稿子在这儿只会两头漂移（`antd-theme.ts` 已经比落地版多出一行 `cellPaddingBlock`）。

留下的这两份稿子还没落地：`users.html` 的列表骨架尚未重排（列表页目前是靠重定义
旧类名换的皮），`permissions.html` 的权限矩阵完全没实现 —— `RoleForm.tsx` 还是旧的
复选框树，矩阵的 `.ap-mx` 样式躺在 `ui.css` 里没人用。它们是待办，不是存档。

稿件中的用户、角色、日志均为演示数据，用来体现密度和状态多样性，不是线上真实数据。

## 参照

x.ai / Grok 的授权页那一屏：纯白底、零彩度、一个很大的紧字距标题、一行小灰字说明，
权限项是「一个线性图标 + 一句人话」，行与行之间只有一条发丝线，右下角两颗胶囊按钮
（拒绝＝白底细描边，允许＝实心黑）。整屏没有一个色块、没有一处投影，
信息层级完全由**字号、留白、线**三样东西撑起来。

这套语言对后台的意义在于：权限系统的界面本来就该像一份**授权书**，
而不是像一个仪表盘。读者要回答的是「谁能碰什么」，不是「今天涨了多少」。

## 这一版推翻了上一版的什么

上一版是「暖白 / 松石」。那一版解决的是旧版发闷、没主次的问题，方向没错；
这一版换的是更根本的东西 —— 用**减法**建立层级，而不是用明暗和投影。
下面每一条都是**明确的反转**，看到旧文档里的说法以这里为准：

| 上一版（暖白 / 松石） | 这一版（纯白 / 墨黑） |
|---|---|
| 侧栏 `#F1EEE8` → 工作区 `#F8F6F2` → 卡片 `#FFFFFF` 三层明度递进 | **全部纯白**。侧栏和工作区之间只有一条 `#E3E3E3` 发丝线 |
| 卡片 `0 1px 3px` + 浮层 `0 6px 18px` 两档投影 | **零投影**。只有浮层（Modal / Drawer / Dropdown）保留一档 |
| 强调色松石 `#145E63` | **强调色就是墨黑 `#0A0A0A`**，链接也是黑字 + 发丝下划线，没有链接蓝 |
| 头像用色块区分、徽章带浅色底 | 头像统一中性灰，徽章去掉底色，**颜色只剩那颗 7px 圆点** |
| 「刻意不用 Inter」（当时为了躲开 AI 生成界面的通用感） | **Inter / Inter Tight 回来了**。躲开通用感靠的是排版克制，不是换一个字体 |
| 圆角统一 10 / 6 | **形状分工**：按钮/徽章/标签是胶囊 `999`，卡片 `14`，输入框 `10` |
| 页标题 21 / 卡片标题 15 / 正文 13.5 | 页标题 **30**（字距 `-.03em`）/ 卡片标题 17 / 正文 14 |

保留没变的：焦点唯一（一屏最多一个主按钮）、导航结构对齐真实菜单树、
不显示编造的数据、中文排版的两条规则（见下）。

## 方案要点

**1 · 结构全部交给发丝线**
分隔只有两种线：区块边界 `--ap-card-line #E3E3E3`，区块内部 `--ap-line #EDEDED`。
指标条不再是四张浮起来的卡，而是一条上下封口、中间用竖线分栏的**带**；
表头没有底色，只有一条线。没有底色和投影之后，**留白就是唯一的间距语言** ——
所以卡片内边距给到 24、表格行高给到 60，这不是浪费，是这套语言的主料。

**2 · 字号层级 + 负字距**
`30 / 17 / 15 / 14 / 12.5 / 11.5`，指标数字 34。
标题用 Inter Tight 并收紧字距（`-.03em`），大字才立得住 —— 这是参照稿里
最容易被忽略、却最决定气质的一条。中文标题不收字距（`--ap-tr-page` 只挂在显示字体上）。

**3 · 形状携带语义**
胶囊 = 可点击，圆角矩形 = 可输入。两者形状不同，扫一眼就分得开，
不需要靠颜色提示。主按钮实心黑、次按钮白底细描边 —— 就是参照稿右下角那两颗。

**4 · 颜色只留给状态**
整套系统只有三个彩色值：`#067647` `#B54708` `#B42318`，
而且只以 7px 圆点的形式出现（徽章、环境条、动态流头像角标、异常指标后缀）。
文字永远是黑或灰。一旦出现第四个彩色，这套语言就散了。

**5 · `.ap-rows` —— 参照稿的签名组件**
一个线性图标 + 一句人话 + 右侧一个值，行间一条发丝线。
`permissions.html` 的「保存后会发生什么」用的就是它：把「按下保存会影响谁、
多少人在线、何时生效、记到哪」摊成四行人话，而不是一个键值对表格。
凡是要让管理员**读懂一次操作的后果**的地方，都用它。

## 四条硬约束

违反任意一条，这套语言立刻退回「又一个后台模板」。落地后跑这几条 grep，应该都是空的：

```bash
grep -rn "linear-gradient"            frontend/src --include=*.css
grep -rn "backdrop-filter"            frontend/src --include=*.css
grep -rn "box-shadow"                 frontend/src --include=*.css   # 只允许出现在浮层
grep -rn "text-transform: *uppercase" frontend/src --include=*.css
```

1. **不用渐变装饰。** 旧版的 `#6366f1 → #8b5cf6` 135° 靛紫渐变是当下 AI 生成界面
   最标志性的一对颜色，占掉大量视觉预算却不传达信息。
2. **不用玻璃拟态、不用投影做分层。** 除浮层外一律零投影；「抬起」靠发丝线和留白。
   这一条比上一版更严 —— 上一版还允许卡片有 `0 1px 3px`。
3. **不加第四个彩色。** 强调色是黑；绿/橙/红只表达状态，只出现在圆点上。
4. **不显示编造的数据。** 旧版首页在总数是 3 和 6 的卡片上标了 `↑5.2%` `↑2.1%` `↓1.5%`，
   这些百分比是硬编码的。对比值必须是真实绝对数并注明基准（「昨日全天 63」而不是「+33%」），
   拿不到基准就不写这一行。

另外两条中文排版规则（沿用）：

- **表头不做 `uppercase` + 字距拉伸。** 中文没有大小写，uppercase 无效，
  而 letter-spacing 会把「用户姓名」硬拆成四个孤字。这是英文模板套中文留下的痕迹。
- **字重只用 400 / 500 / 600。** 这一版连 700 都不再用 —— 纯白底上 600 已经够重，
  700 在小字号下渲染出来是脏而不是重。标题的分量来自 30px 和紧字距，不是来自字重。

## 落地状态

设计稿已经落到 `frontend/`，下面是实际发生的改动。

### 1 · 样式三层

```
frontend/src/styles/theme.css   令牌，唯一真源
frontend/src/styles/ui.css      .ap-* 组件层（设计稿同名文件去掉稿件导航条）
frontend/src/styles/antd.css    AntD 对齐层，设计稿里没有，落地时新写
```

`src/index.css` 从 194 行缩到 20 行，只剩三条 `@import` 和一句 `height: 100%`。

`src/main.tsx` 的引入顺序被改过，这一点比看上去重要：

```ts
import 'normalize.css';
import 'antd/dist/reset.css';
import './index.css'          // 我们的三层排在最后
```

旧版是 `index.css` 在前、antd 的 reset 在后 —— 每条自定义规则都会被 reset 盖掉，
那一整屏 `!important` 就是这么逼出来的。换了顺序之后，只有 AntD 运行时用
CSS-in-JS 注入的那部分还需要 `!important`（它插在 `<head>` 末尾，链接样式表之后）。

### 2 · ConfigProvider

`src/config/theme.ts` 现在是这份 `ConfigProvider` 配置的唯一版本，`App.tsx` 里那段
内联的靛紫主题换成了 `theme={antdTheme}`。

关键点：`colorPrimary` 给 `#0A0A0A`，主按钮 / 链接 / 焦点环 / 选中行 / Tabs 墨条
一起变成黑白。`boxShadow` 和 `boxShadowTertiary` 显式给 `none`，
只给 `boxShadowSecondary` 留浮层那一档 —— AntD 默认会给按钮和卡片塞投影，
不显式关掉，这套语言就守不住。`borderRadius: 999` 是全局默认（按钮是胶囊），
输入类控件在 `components` 里单独压回 `10`。

一处刻意的偏差：`Table.cellPaddingBlock` 没有放进 theme.ts。AntD 的这个令牌会同时
作用于表头和内容，而设计要的是表头 44、行高 60 两个不同的值，所以行距只写在
`styles/antd.css` 里（`thead` 11px / `tbody` 18px），避免两处真源打架。

## 无障碍

纯白底上的文字对比度（`#FFFFFF` 为背景）：

| 令牌 | 色值 | 对比度 | 用途 |
|---|---|---|---|
| `--ap-text` | `#0A0A0A` | 19.8:1 | 正文、标题 |
| `--ap-text-2` | `#5C5C5C` | 6.7:1 | 次要文字、导航未选中 |
| `--ap-text-3` | `#757575` | 4.6:1 | 元信息、表头（刚过 AA 4.5:1，不要再调浅） |
| `--ap-ok` | `#067647` | 5.7:1 | 正常 |
| `--ap-warn` | `#B54708` | 5.4:1 | 警告 |
| `--ap-bad` | `#B42318` | 6.6:1 | 异常 |

AntD 的 `colorTextQuaternary #9E9E9E` 只有 2.7:1，**仅用于 disabled 和 placeholder**，
不要拿它承载任何需要读的信息。

状态徽章一律「圆点 + 文字」且**去掉了底色**，形状和文案都携带信息，
不单靠颜色区分，色盲用户同样可读。权限矩阵的四种格子除颜色外还有形状差异
（实心 / 内嵌环 / 浅灰 / 短横），也不依赖颜色。
所有控件常驻文字标签，不拿 placeholder 当标签。
焦点态是 2px 墨黑描边 + 3px 浅灰光环，在纯白底上是全页最重的一处，键盘可见。
`prefers-reduced-motion` 下所有过渡时长归零。

**一处已知的取舍**：发丝线 `#EDEDED`（1.1:1）和输入框描边 `#D2D2D2`（1.5:1）
都达不到 WCAG 1.4.11 对非文字元素的 3:1。这是这套语言的代价 —— 缓解手段是
每个控件都有常驻标签、焦点态用纯黑。如果项目必须严格达标，
把 `--ap-field` 调到 `#949494`（正好 3.0:1）即可，其余不用动。
